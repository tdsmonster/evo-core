# M5 能力感知模块

> **来源论文**: Skill0.5 (arXiv:2605.28424) + Continual Harness (arXiv:2605.09998)
> **依赖**: 无
> **适用**: 类型2/3（多模型并用、本地小模型参与的架构）

---

## 论文核心主张

- **Skill0.5**: 通用行为内化 + 易变任务技能外挂双轨制；反事实检验（撤除技能看是否退化）。
- **Continual Harness**: 能力地板效应——弱模型配复杂组件反而更差，组件复杂度必须匹配模型能力。

## AI 可解析核心

### ① 模型分层规则

```
强模型（云端/大模型）→ 完整版组件（全细节、多分支）
弱模型（本地小模型）→ 精简版组件（核心步骤 + 关键约束，砍分支）
```

### ② 能力地板精简原则

```
只精简「该模型实际会接触的组件/供给内容」——
  ✗ 不盲目拆全部（审计标记的高风险技能中，大部分是强模型专用，弱模型不碰）
  ✓ 优先知识/指令供给侧精简：给弱模型高频检索的长文档配精简摘要版
  ✓ 弱模型走 RAG 知识供给的，精简供给内容，而非拆组件本体
```

### ③ 反事实抽查（防走捷径）

- 定期抽检: 该任务的执行是否真遵循了 skill 约束，还是凭内部先验"脑补"？
- 方法: 提取 skill 硬约束（必须/禁止/⚠️），比对执行记录中的偏离；偏离率 >10% 触发加强执行。

### ④ 动静分层

- 通用行为直觉（强约束/内化）vs 易变任务技能（外挂/随需加载）分离管理。

## 适用场景

- 多模型并用的 Agent（本地小模型 + 云端大模型）；防止小模型被复杂组件拖垮。
