# EVO-CORE X · 自主认知与机器证据架构规范 (v2.0)

> **官方定名**: **EVO-CORE X: Autonomous Cognitive, Multi-Tiered Evidence & Execution Architecture**  
> **定位**: 次世代通用智能体（Agent）认知演进与客观验证架构规范（形式化方法论，纯通用技术规范，0% 私有业务与个人信息）。  
> **演进关系**: 从 v1.0 单体 Agent 反馈循环演进为 **四大自主认知引擎（Four Cognitive Engines）** + **异构算力调度（Heterogeneous Compute）** + **零 LLM 成本机器单测硬验收（Zero-LLM Evidence Gate）**。

---

## 0. 范式跃迁 (从 EVO-CORE v1.0 到 EVO-CORE X)

| 核心维度 | EVO-CORE v1.0 (经典代) | EVO-CORE X (次世代) |
|---|---|---|
| **认知核心** | 单 Agent Prompt 与 Memory 反馈循环 | **四大解耦自主认知引擎 (Four Cognitive Engines)** |
| **算力调度** | 单一同质模型依赖 | **三层异构算力协作矩阵 (Arbiter 决策裁判 / Distiller 离线提炼 / Worker 高吞吐工兵)** |
| **验证机制** | 依赖 LLM 自我反思或主观 Text Gradients | **客观证据引擎 (Evidence Engine: 0 LLM 机器单测硬断言与 AST 语法门禁)** |
| **执行边界** | 开放式工具链直接执行 | **零泄漏沙箱生命周期 (Ephemeral Sandbox: 用完即销毁，0 内存泄漏)** |
| **状态治理** | 非参数化 Prompt/Skill 演进 | **四大引擎闭环契约 (World Model, Knowledge, Evidence, Alignment)** |

## 一、 四大自主认知引擎 (Four Autonomous Cognitive Engines)

EVO-CORE X 将智能体的自主认知与执行彻底解耦为四大非重叠引擎：

```
                      ┌─────────────────────────────────┐
                      │    1. 世界模型引擎 (World Model)  │
                      │   (环境拓扑 / 服务状态 / 实时探针)   │
                      └───────────────┬─────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────┐       ┌─────────────────────────────────┐
│     2. 知识引擎 (Knowledge)      │       │     3. 证据引擎 (Evidence)      │
│  (分层 RAG 检索 / 确定性 SOP 库)  │◄─────►│ (机器单测硬断言 / 语法安全门禁)  │
└────────────────┬────────────────┘       └────────────────┬────────────────┘
                 │                                         │
                 └────────────────────┬────────────────────┘
                                      │
                                      ▼
                      ┌─────────────────────────────────┐
                      │    4. 对齐引擎 (Alignment)      │
                      │   (意图裁判 / 安全边界 / 风险回滚)   │
                      └─────────────────────────────────┘
```

### 引擎 1 | 世界模型引擎 (World Model Engine)
- **职责**: 维护外部环境、依赖拓扑、网络探针与服务健康状态的客观表征。
- **核心公理**: *智能体在缺乏明确、可验证的世界状态表征时，严禁发起破坏性/状态变更动作。*
- **执行准则**:
  - 确定性实时探针优先于主观记忆推测（主动 TCP/ICMP/API 握手校验）。
  - 在执行任何跨服务操作前，必须显式构建拓扑依赖图。

### 引擎 2 | 知识引擎 (Knowledge Engine)
- **职责**: 管理情景记忆、领域知识与操作流程，保障上下文窗口不被无效垃圾信息挤爆。
- **核心公理**: *检索可用性 > 结构稠密度 > 推理算力开销。*
- **执行准则**:
  - 严格隔离陈述性知识（事实/参数/规范）与程序性知识（可执行 SOP/脚本）。
  - 面向端侧小模型执行前置确定性上下文注入，从物理层面根除幻觉。

### 引擎 3 | 证据引擎 (Evidence Engine)
- **职责**: 生产、断言并记录不可篡改的执行正确性物理证据。
- **核心公理**: *智能体的自我陈述（Self-Report）绝非事实，零 LLM 消耗的机器断言是唯一真理。*
- **执行准则**:
  - **机器硬验收门禁**: 所有代码、配置文件、数据处理产物必须在临时沙箱中通过确定性单元测试（`unittest`/`pytest`）或 AST 静态检查，方可合入主系统。
  - **短生命周期沙箱 (Ephemeral Sandbox)**: 高吞吐执行工兵必须在隔离沙箱中运行，任务结束后立即销毁沙箱环境，保障 0 进程与内存泄漏。

### 引擎 4 | 对齐引擎 (Alignment Engine)
- **职责**: 充当用户意图、安全红线、风险分级与不可逆操作的最高裁判。
- **核心公理**: *自主执行必须在法定安全边界（金钱/销毁/权限凭据）前严格挂起并触发审计。*
- **执行准则**:
  - 高阶推理模型充当决策裁判（Arbiter）；高吞吐轻量模型充当无状态执行工兵（Worker）。
  - 超出单轮安全阈值的任何系统状态变更，必须强制具备可验证的回滚快照。

## 二、 异构三层算力协作矩阵 (Heterogeneous Compute Scheduling)

```
┌────────────────────────────────────────────────────────────────────────┐
│ 第一层：最高对齐与意图裁判 (Tier 1: Cloud Frontier Model - Arbiter)    │
│ → 复杂意图拆解、跨领域多步推理、安全边界裁决、最终意图合入             │
├────────────────────────────────────────────────────────────────────────┤
│ 第二层：边缘隐私与离线提炼 (Tier 2: Edge Quantized Model - Distiller)  │
│ → 零 API 成本私有数据脱敏、RAG 向量打标、高频健康巡检与日志摘要        │
├────────────────────────────────────────────────────────────────────────┤
│ 第三层：高吞吐无状态工兵 (Tier 3: Clustered API Pool - Worker)         │
│ → 海量代码生成、AST 转换、批量长文解析；由证据引擎沙箱约束（用完即毁） │
└────────────────────────────────────────────────────────────────────────┘
```

## 三、 多级证据流水线 (Multi-Tiered Evidence Pipeline)

所有任务在 EVO-CORE X 体系下严格流转于以下 5 步不可逆证据链：

```
[用户意图输入]
      │
      ▼
┌──────────────┐
│  对齐引擎    │ ─── (风险评估与授权边界检查)
└──────┬───────┘
       │ [通过授权]
       ▼
┌──────────────┐
│  世界模型    │ ─── (探测目标拓扑与环境真实状态)
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  工兵算力池  │ ─── (在临时沙箱目录中无状态生成代码与产物)
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  证据门禁    │ ─── (零 LLM 机器单测 / AST 语法检查 / 物理证据断言)
└──────┬───────┘
       │ 验收通过: 合入产物并立即销毁临时沙箱 (0 内存泄漏)
       │ 验收失败: 将真实 Traceback 回传文本梯度引擎重试 (上限 3 次)
       ▼
[交付验证结果]
```
